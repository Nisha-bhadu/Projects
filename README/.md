# 🏠 Smart Home Environment Monitoring System

An embedded IoT project built on the **ESP32** that monitors room **temperature**, **humidity** and **light intensity** in real time. Readings are shown on the Serial Monitor, and an **alert** (Serial message + LED + buzzer) is generated when temperature or humidity crosses a set limit.

Simulated on [Wokwi](https://wokwi.com/).

---

## 📌 Features

- 🌡️ Measures temperature and humidity using a **DHT22** sensor
- 💡 Measures light intensity using an **LDR module** and classifies it as `DARK`, `NORMAL` or `BRIGHT`
- 🖥️ Prints all readings on the **Serial Monitor** every 2 seconds
- 🚨 Generates an **alert** when:
  - Temperature > **35 °C**
  - Humidity > **70 %**
- 🔴 Alert indication through a **red LED** and a **buzzer**
- ⚙️ Alert limits are easy to change in the code

## 🔌 Circuit Connections

| Component | Component Pin | ESP32 Pin |
|---|---|---|
| DHT22 | VCC | 3V3 |
| DHT22 | GND | GND |
| DHT22 | SDA (Data) | GPIO 4 |
| LDR module | VCC | 3V3 |
| LDR module | GND | GND |
| LDR module | AO (Analog out) | GPIO 34 |
| LED | Anode (via 220 Ω resistor) | GPIO 2 |
| LED | Cathode | GND |
| Buzzer | Positive | GPIO 25 |
| Buzzer | Negative | GND |

> GPIO 34 is an input-only ADC1 pin, which makes it a good choice for reading the analog LDR output.

## 🚀 How to Run (Wokwi)

1. Open [wokwi.com](https://wokwi.com/) and create a new **ESP32** project.
2. Replace the content of `sketch.ino`, `diagram.json` and `libraries.txt` with the files from this repository.
3. Click the green **Play** button to start the simulation.
4. Open the **Serial Monitor** to see the readings.

## 🧪 Testing the Alerts

While the simulation is running:

| Test | What to do | Expected result |
|---|---|---|
| High temperature | Click the DHT22 and set temperature above 35 °C | Alert message, LED ON, buzzer beeps |
| High humidity | Click the DHT22 and set humidity above 70 % | Alert message, LED ON, buzzer beeps |
| Light change | Click the LDR module and change the lux slider | Light % and status change |
| Normal values | Bring values back within limits | `Status: All OK`, LED OFF |

## ⚙️ Configuration

Change these values at the top of `sketch.ino`:

```cpp
const float TEMP_LIMIT = 35.0;   // °C
const float HUM_LIMIT  = 70.0;   // %

const int DARK_LIMIT   = 30;     // light % below this = DARK
const int BRIGHT_LIMIT = 70;     // light % above this = BRIGHT
```

If the light percentage reads inverted for your LDR module, swap the mapping:

```cpp
int lightPercent = map(ldrRaw, 0, 4095, 100, 0);
```
